# UI 视觉需求文档（当前版）

更新时间：2026-05-07

## 1. 文档目标
本文档用于固化当前客户端的视觉基线。当前版本不再严格复刻单一旧网易云界面，而是以浅色桌面音乐客户端为基础，融合更现代的圆角卡片、轻量控制栏、内容型推荐页和全屏播放页。

## 2. 当前视觉基线

### 2.1 总体方向
- 主体为浅色桌面音乐客户端；
- 红色强调承担品牌动作色和播放控制强调色；
- 控件风格从早期方正样式调整为更柔和的圆角系统；
- 左侧导航贯穿窗口高度，承担主功能切换和账号入口；
- 右侧内容区承载搜索、页面内容和收起态播放控制；
- 播放页展开后保持沉浸式全屏样式。

### 2.2 当前配色原则
- 主强调色：`#EC4141`
- 强调 hover：浅红或柔和红底
- 主背景：白色或接近白色的浅灰底
- 主要文字：深色
- 次级文字：灰蓝色
- 分割线与描边：浅灰蓝色
- 播放页背景：允许按播放页风格或封面氛围动态变化

### 2.3 当前圆角与组件语言
- 主窗口左侧栏：圆角白色面板；
- 列表行：轻圆角，hover 时呈现封面播放态和动作条；
- 弹窗与卡片：中等圆角；
- 主控制按钮：圆形或胶囊形；
- 播放页风格按钮、桌面歌词按钮、评论按钮：统一圆形工具按钮；
- 输入框、下拉框、菜单、滚动条、进度条：统一圆角，不再使用硬直角。

## 3. 当前页面级视觉要求

### 3.1 欢迎页
- 以轻表单卡片为主；
- 右下角主按钮承担主要动作；
- “不连接，直接进入”采用轻量文本入口；
- 欢迎页品牌展示只服务启动流程，不等同主窗口导航品牌块。

### 3.2 主窗口与左侧导航
- 左侧导航栏竖直贯穿窗口高度；
- 用户头像入口位于左侧导航顶部；
- 导航栏不再展示“云音乐”标题图标；
- 顶部工具栏只覆盖右侧内容区，搜索、菜单和窗口控制保持在右侧区域；
- 导航按钮保持统一高度、圆角、红色选中态。

### 3.3 列表、推荐与热歌榜
- 本地、下载、在线、收藏、历史列表保持统一行高、封面、动作条和 hover 语言；
- 推荐页允许更内容化的模块布局；
- 热歌榜使用榜单 Hero 区 + 列表行组合；
- 榜单歌曲的播放、收藏、下载、加歌单、评论入口需与普通在线歌曲一致。

### 3.4 播放页
- 播放详情页展开后保持全屏舞台布局；
- 左侧唱片/封面与右侧歌词区域共享基线；
- 收起态控制栏位于右侧内容区底部；
- 展开态控制栏背景透明，使用播放页背景；
- 进度条位于一排控制按钮下方，长度随中心控制区调整；
- 播放页风格切换按钮为圆形衣服图标，放在桌面歌词按钮左侧；
- 主控制栏图标保持同一线性 SVG 风格。

### 3.5 评论与桌面歌词
- 评论面板应作为播放页能力，不抢占主列表页视觉重心；
- 评论读写状态需要区分未登录、在线歌曲、本地歌曲和网络失败；
- 桌面歌词按钮保持工具按钮风格；
- 桌面歌词配置页应展示字体、颜色、透明度、对齐、行模式等设置的即时语义。

### 3.6 个人主页
- 个人主页采用内容流布局；
- 资料头部突出头像、用户名和状态；
- 资料页按钮保持轻、细、克制；
- 头像上传与用户名修改是头部轻入口，而不是后台表单式布局。

## 4. 当前资源约束
- 图标资源优先使用统一 SVG；
- 默认封面、默认头像、主控制栏图标和列表动作图标应保持同一视觉族；
- 播放控制新增图标必须注册到 `qml.qrc`；
- 同一页面内禁止混用明显不属于同一套的图标语言；
- `styles/netease.qss` 和 `qml/theme/Theme.js` 应保持视觉 token 语义一致。

## 5. 当前版本结论
后续所有 UI 调整都应以当前真实界面为基线：
- 主窗口是“左侧贯穿导航 + 右侧内容区 + 底部/全屏播放层”；
- 账号入口属于左侧导航顶部，不属于右上角工具栏；
- 列表与播放链路偏网易云式轻桌面播放器；
- 推荐、热歌榜、个人主页更偏内容流；
- 总体原则是轻量、圆润、清晰、统一，而不是回到方正控件风格。
