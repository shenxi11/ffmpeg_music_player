# 客户端模块目录索引（当前版）

更新时间：2026-05-07

## 1. 目录总览

### 1.1 C++ 目录
- `src/app`：应用启动、主窗口壳层、左侧导航、顶部工具栏、页面装配、插件菜单、账号入口连接与运行模式控制。
- `src/audio`：音频解码、音频会话、共享播放器、缓冲控制与音频播放服务。
- `src/video`：视频解码、缓冲、渲染、播放窗口与视频媒体会话。
- `src/playback`：音视频焦点切换与播放状态管理。
- `src/network`：`HttpRequestV2`、在线接口适配、响应解析、在线状态维护。
- `src/download`：下载任务、下载管理、本地音乐模型与本地元数据缓存。
- `src/lyrics`：歌词解析、桌面歌词窗口与歌词编辑相关能力。
- `src/models`：`Music`、用户、视频等基础数据模型。
- `src/common`：配置、日志、封面查询、通用工具与共享状态。
- `src/ui/widgets`：Widgets 层页面宿主，包括认证、列表、播放、用户、设置、视频等页面容器。
- `src/ui/qml_bridge`：QML 页面桥接对象，负责把 QML 信号转为 QWidget/C++ 信号。
- `src/viewmodels`：主壳、播放、登录、欢迎页、设置、视频、在线列表、本地列表等 ViewModel。
- `src/tools`：独立工具窗口或辅助功能模块。

### 1.2 QML 目录
- `qml/components/auth`：登录页与认证相关表现层。
- `qml/components/user`：左侧导航顶部账号入口、用户弹窗、个人主页。
- `qml/components/search`：搜索框表现层。
- `qml/components/library`：本地、下载、在线、推荐、热歌榜、收藏、歌单列表及通用列表动作组件。
- `qml/components/playback`：播放详情页控制栏、进度条、播放历史、播放队列、评论面板、播放页风格弹窗。
- `qml/components/lyrics`：歌词显示与桌面歌词相关页面。
- `qml/components/video`：视频列表与视频播放页。
- `qml/components/settings`：设置页，含桌面歌词、播放页样式、路径与服务端配置。
- `qml/theme`：全局主题 token 与播放页风格 token。
- `qml/assets`：图标、默认封面、默认头像、播放控制图标等资源。

## 2. 当前主窗口相关模块

### 2.1 `src/app`
- `main.cpp`：应用启动、欢迎页验证、离线直进与主窗口装配入口。
- `main_widget.cpp/.h`：当前主窗口真实壳层，负责左侧贯穿导航、页面区域、播放层、顶部工具栏、账号入口和全局布局。
- `main_widget.library_connections.cpp`：列表页、推荐、热歌榜、歌单、用户资料与主窗口连接。
- `main_widget.menu_auth.cpp`：登录、个人主页、欢迎页返回、头像资料相关连接。
- `main_widget.playback_connections.cpp`：播放页、列表封面动作、元数据回写连接。
- `main_widget.playback_list_handlers.cpp`：播放列表相关交互与离线模式保护。
- `main_widget.playback_state_handlers.cpp`：播放页展开/收起、视频/音频焦点与统一播放状态回写。
- `main_menu.cpp/.h`：顶部菜单、插件入口、设置入口与窗口级操作。
- `plugin_manager.*` / `plugin_host_*`：插件发现、诊断、宿主上下文与插件窗口装配。

### 2.2 `src/viewmodels`
- `MainShellViewModel`：主壳业务聚合中心，负责账号、资料、推荐、热歌榜、评论、收藏、历史、歌单、下载、本地缓存回写。
- `PlaybackViewModel`：播放状态唯一真相源，负责当前曲目、封面、歌手、位置、时长、队列快照。
- `LoginViewModel`：登录、注册、密码重置。
- `ServerWelcomeViewModel`：欢迎页服务端验证与 bootstrap。
- `SettingsViewModel`：设置页对 `SettingsManager` 的 QML 暴露层。
- `LocalMusicListViewModel` / `OnlineMusicListViewModel` / `VideoListViewModel`：对应页面的数据入口。

## 3. 当前页面宿主与桥接

- `src/ui/widgets/user/user_profile_widget.*`：个人主页 `QQuickWidget` 宿主。
- `qml/components/user/UserWidget.qml`：账号入口表现层。
- `qml/components/user/UserPopupWindow.qml`：用户弹窗表现层。

### 3.2 列表、推荐与下载
- `src/ui/widgets/library/music_list_widget_local.*`：本地音乐列表宿主。
- `src/ui/widgets/library/music_list_widget_net.*`：在线音乐列表宿主。
- `src/ui/widgets/library/recommend_music_widget.*`：推荐页宿主，连接推荐列表与热歌榜。
- `src/ui/widgets/library/local_and_download_widget.*`：本地 / 下载 / 正在下载容器。
- `src/download/download_task_model.*`：下载列表直接消费的模型。
- `qml/components/library/RecommendMusicWidget.qml`：推荐页与在线热歌榜表现层。
- `qml/components/library/SongCoverAction.qml`：统一封面播放交互组件。

### 3.3 播放、评论与歌词
- `src/ui/widgets/playback/play_widget.*`：播放详情页、播放状态、评论入口和控制链桥接。
- `src/ui/qml_bridge/playback/comment_panel_qml.h`：评论面板 QML 桥接。
- `src/ui/qml_bridge/playback/playlist_history_qml.*`：播放队列桥接。
- `qml/components/playback/ProcessSlider.qml`：当前主控制栏 QML，包含进度条、播放按钮、桌面歌词、评论和播放页风格入口。
- `qml/components/playback/PlayerStylePopup.qml`：播放页风格选择弹窗。
- `qml/components/playback/CommentPanel.qml`：在线音乐评论面板。
- `qml/components/lyrics/LyricDisplay.qml`：歌词显示与播放页歌词卡片。

### 3.4 设置、视频与插件
- `src/ui/widgets/settings/settings_widget.*`：设置页宿主。
- `qml/components/settings/Settings.qml`：设置页表现层，含播放页样式与桌面歌词配置。
- `src/ui/widgets/video/video_list_widget.*`：视频列表与视频播放入口。
- `src/video/*`：`MediaSession`、`VideoSession`、`VideoRendererGL` 等视频核心。
- `src/app/plugin_*`：插件管理、插件窗口、插件上下文和诊断。

## 4. 当前高价值公共模块
- `src/common/settings_manager.*`：账号、资料、欢迎页、播放页样式、桌面歌词等持久化配置。
- `src/common/cover_lookup.*`：封面记忆查询与补偿。
- `src/download/local_music_cache.*`：本地歌曲封面、歌手、时长缓存。
- `src/network/httprequest_v2.*`：业务 HTTP 接口适配层。
- `src/network/online_presence_manager.*`：在线会话状态维护。
- `qml/theme/Theme.js`：QML 颜色、圆角、阴影、间距等视觉 token。
- `qml/theme/PlayerStyle.js`：播放页风格 token。

- 左侧导航贯穿主窗口高度，账号入口移动到左侧导航顶部，导航栏品牌标题和图标已移除。

- 全局控件风格从方正改为更柔和的圆角卡片和圆形控制按钮。

## 7. 结论
当前客户端结构可以概括为：
- `MainWidget` 负责主窗口壳层、左侧导航、运行模式和跨页面连接；
- `MainShellViewModel` 负责业务聚合；
- `PlaybackViewModel` 负责播放状态统一；
- Widgets 负责宿主，QML 负责表现层和局部交互；
- 网络、下载、本地缓存、设置、插件、音视频核心能力分别在独立模块中维护。
