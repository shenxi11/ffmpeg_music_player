更新时间：2026-05-07

## 1. 文档目的
本文档从“用户功能视角”和“代码实现视角”梳理当前客户端真实结构，作为后续说明文档补充、PPT 架构图输入和毕业论文系统结构章节底稿。

本文档只描述当前工作区主链，不把历史原型、备用 QML 主壳、旧 Agent sidecar 或不存在的目录写成当前真相。

## 4. 当前主链模块说明

### 4.1 桌面运行主链
当前桌面主链是：
- `main.cpp -> ServerWelcomeDialog -> MainWidget`
- `MainWidget` 负责壳层、左侧导航、页面装配、模式控制与全局连接
- `MainShellViewModel` 负责账号、资料、热歌榜、评论、歌单、推荐、历史、收藏、下载等业务聚合
- `PlaybackViewModel` 负责播放状态统一输出

### 4.2 页面与状态分工
当前客户端采用 Widgets + QML 混合组织：
- `src/ui/widgets` 负责页面宿主；
- `qml/components` 负责表现层和局部交互；
- `src/viewmodels` 负责业务状态和请求入口；
- `src/common` / `src/network` / `src/download` / `src/audio` / `src/video` 负责底层能力。

### 4.3 当前 Agent / 自动化定位
当前工作区没有 `src/agent` 目录，也没有可作为当前真相源的 `ToolRegistry.cpp` / `AgentToolExecutor.cpp`。因此：
- 旧 Agent、sidecar、websocket、`8765` 相关内容只作为历史说明或待恢复能力；
- 当前客户端模块说明不再把 Agent 工具接口作为运行主链；
- 如后续恢复 Agent，应先恢复源码，再重新生成开放接口清单。

## 5. 兼容层与历史残留说明
以下内容仍可保留在仓库中，但不应再作为当前客户端主链来理解：

- `qml/MainView.qml` 备用/历史 QML 主壳；
- `src/app/main_qml.cpp`；
- 旧 `ControlBar` / `CustomControlBar` 控制栏路径；
- `src/ui/widgets/user/user_widget.*` 的旧 QWidget 用户入口；
- 旧 Agent / sidecar / websocket / 8765 相关文档。

## 6. 可直接复用的结论
如果后续要把当前软件结构写成 PPT 或论文摘要，可以直接提炼为以下结论：

1. 客户端当前已经形成“主窗口壳层 + ViewModel 业务聚合 + Widgets/QML 混合页面 + 核心能力层”的清晰分层；
2. `MainShellViewModel` 和 `PlaybackViewModel` 分别承担业务状态轴与播放状态轴；
3. 本地、下载、歌单、推荐、热歌榜、评论、用户资料、视频、设置与插件都已纳入当前统一客户端结构；
4. 当前工作区没有 Agent 主链源码，旧 Agent 自动化接口不应作为当前客户端功能描述依据。
