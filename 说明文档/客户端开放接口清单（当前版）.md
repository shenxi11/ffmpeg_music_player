# 客户端开放接口清单（当前版）

更新时间：2026-05-07

## 1. 接口总说明

本文档描述当前客户端可确认的“对外协作面”和“跨模块桥接入口”。这里的接口不等同于服务端 HTTP API，也不等同于 QML 内部控件树。

当前工作区没有 `src/agent` 目录，也没有 `ToolRegistry.cpp` / `AgentToolExecutor.cpp`。因此，旧文档中“87 个 Agent 工具接口”的说法已不再作为当前真相源。若后续恢复 Agent 自动化层，需要以恢复后的源码重新审计。

服务端 HTTP API 以以下文档和 Apifox OpenAPI 为准：
- `说明文档/接口与协议/在线热歌榜接口与客户端实现说明.md`
- `说明文档/接口与协议/在线音乐评论接口与客户端实现说明.md`
- `说明文档/接口与协议/服务端新增接口.md`
- `说明文档/接口与协议/接口变化.md`
- `/home/shen/CloudMusic/docs/apifox-client-openapi.yaml`

## 2. 当前客户端接口分层

| 层级 | 当前真相来源 | 用途 | 说明 |
|---|---|---|---|
| QML 信号接口 | `qml/components/**/*.qml` | 页面交互到宿主 | 例如热歌榜刷新、评论提交、播放页风格选择 |
| QML 桥接接口 | `src/ui/qml_bridge` | QML 与 QWidget/C++ 连接 | 将 QML 信号转换为 C++ 信号或槽 |
| 主壳协调接口 | `src/app/main_widget*.cpp` | 页面装配、导航、运行模式、跨页面连接 | 当前 UI 运行主链 |
| ViewModel 业务接口 | `src/viewmodels` | 账号、推荐、热歌榜、评论、歌单、设置等业务入口 | 业务状态与请求聚合 |
| 网络接口适配 | `src/network/httprequest_v2.*` | 服务端 HTTP API 访问 | 只负责协议适配和响应解析 |
| 设置接口 | `src/common/settings_manager.*` + `SettingsViewModel` | 持久化配置与 QML 暴露 | 播放页样式、桌面歌词、服务端配置等 |
| 插件接口 | `src/app/plugin_*` | 插件发现、诊断、宿主上下文 | 属于客户端插件系统，不是 Agent 工具接口 |

## 5. 历史 Agent 工具接口说明

旧版本文档曾列出 `ToolRegistry + AgentToolExecutor` 下的 87 个工具接口，包括播放、下载、歌单、设置、插件、UI 查询等工具。这些内容当前只能作为历史快照，原因是：

- 当前工作区没有 `src/agent` 目录；
- 当前工作区没有 `ToolRegistry.cpp`；
- 当前工作区没有 `AgentToolExecutor.cpp`；
- 当前客户端没有可验证的 Agent 工具注册表。

如果后续恢复 Agent 自动化层，应执行以下步骤：
1. 恢复或新增 Agent 源码目录；
2. 以实际注册表导出工具清单；
3. 重新生成工具名、参数、读写风险、可用性策略；
4. 再把本节升级为正式开放工具接口表。

## 6. 当前审计结论
- 当前客户端对外协作面以 QML 信号、QML 桥接、`MainWidget` 协调方法、ViewModel 业务接口和 `HttpRequestV2` 网络适配为主；
- 服务端协议不在本文档内重复展开，应引用接口与协议目录及 Apifox OpenAPI；
- Agent 工具接口当前不是可验证主链，不能再作为当前客户端开放接口真相源。
